# Avatar-Ebenen: hani

Vollständiger Ebenensatz für den gezeichneten Hani-Avatar. Der Renderer liest
allein `manifest.json`. Alle animierbaren Ebenen sind PNG mit Alphakanal.

`profile_640.png` ist das Telegram-Profil-/Gruppenbild; die Datei
`profile_640_kreis-vorschau.png` prüft den kreisförmigen Telegram-Zuschnitt.
